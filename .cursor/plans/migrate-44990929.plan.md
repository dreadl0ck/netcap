# Migrate CLI to urfave/cli v3.6.1

## Overview

Migrate from `github.com/namsral/flag` to `github.com/urfave/cli/v3` v3.6.1 across the entire codebase, including main dispatcher and all subcommands.

## Current State

- Uses `namsral/flag` (environment-variable-aware flag package)
- Main entry at `cmd/main.go` with manual routing to 11 subcommands
- Each subcommand has its own `flags.go` and `main.go`
- Environment variable prefix: `NC_`
- Subcommands: capture, util, proxy, label, export, dump, collect, transform, agent, split, analyze

## Migration Strategy

### 1. Update Dependencies

**File: `go.mod`**

- Add `github.com/urfave/cli/v3 v3.6.1`
- Remove `github.com/namsral/flag v1.7.4-pre`

### 2. Restructure Main Entry Point

**File: `cmd/main.go`** (currently ~160 lines)

- Replace manual switch/case routing with `cli.App`
- Create `cli.Command` structs for each subcommand
- Set up app metadata (name, version, usage)
- Preserve bash completion functionality
- Keep version and help commands

**Key considerations:**

- Maintain backward compatibility for existing scripts
- Preserve the custom completion logic (lines 159+)
- Keep the `io.PrintLogo()` and `io.PrintBuildInfo()` calls

### 3. Convert Subcommand Packages (Priority Order)

#### Phase 1: Simple Commands (2-10 flags)

1. **dump** (`cmd/dump/flags.go` - ~15 flags)
2. **export** (`cmd/export/flags.go`)
3. **label** (`cmd/label/flags.go`)
4. **split** (`cmd/split/main.go` - inline flags)

#### Phase 2: Medium Commands (10-30 flags)

5. **util** (`cmd/util/flags.go`)
6. **collect** (`cmd/collect/flags.go`)
7. **agent** (`cmd/agent/flags.go`)
8. **proxy** (`cmd/proxy/flags.go`)

#### Phase 3: Complex Command (100+ flags)

9. **capture** (`cmd/capture/flags.go` - ~130 flags)

**For each subcommand:**

- Convert `flags.go` to return `[]cli.Flag`
- Update `main.go` Run() function to accept `*cli.Context`
- Replace `fs.Parse()` with `cli.Context` methods
- Replace `*flagName` references with `ctx.String("name")` etc.
- Maintain environment variable support with `EnvVars` field

### 4. Handle Special Cases

**Environment Variables:**

- Current: `NC_` prefix via `NewFlagSetWithEnvPrefix`
- urfave/cli: Use `EnvVars: []string{"NC_FLAGNAME"}` on each flag

**Flag Types to Migrate:**

- `Bool` → `cli.BoolFlag`
- `String` → `cli.StringFlag`
- `Int` → `cli.IntFlag`
- `Int64` → `cli.Int64Flag`
- `Duration` → `cli.DurationFlag`

**Config File Support:**

- Current: `config` flag in each subcommand
- Maintain same functionality with urfave/cli

**Special Flags:**

- `gen-config` - config generation utility
- `gen-elastic-indices` - elasticsearch setup

### 5. Update Shared Utilities

**File: `io/utils.go`** (uses namsral/flag)

- Update `GenerateConfig()` function to work with urfave/cli flags
- May need to refactor flag iteration logic

### 6. Testing & Validation

After migration:

- Test each subcommand with various flag combinations
- Verify environment variable overrides work (`NC_*`)
- Test config file loading
- Verify bash completion still functions
- Test help output for all commands
- Ensure backward compatibility

### 7. Documentation Updates

If needed (only for significant behavior changes):

- Update any README files that reference flag syntax
- Note any breaking changes in changelog

## Migration Example (dump command)

**Before** (`cmd/dump/flags.go`):

```go
var (
    fs = flag.NewFlagSetWithEnvPrefix(os.Args[0], "NC", flag.ExitOnError)
    flagCSV = fs.Bool("csv", false, "print output data as csv")
    flagInput = fs.String("read", "", "read specified file")
)
```

**After**:

```go
func Flags() []cli.Flag {
    return []cli.Flag{
        &cli.BoolFlag{
            Name: "csv",
            Usage: "print output data as csv",
            EnvVars: []string{"NC_CSV"},
        },
        &cli.StringFlag{
            Name: "read",
            Usage: "read specified file",
            EnvVars: []string{"NC_READ"},
        },
    }
}
```

**Usage in Run()** - Before:

```go
func Run() {
    fs.Parse(os.Args[2:])
    if *flagCSV { ... }
    input := *flagInput
}
```

**After**:

```go
func Run(ctx *cli.Context) error {
    if ctx.Bool("csv") { ... }
    input := ctx.String("read")
    return nil
}
```
