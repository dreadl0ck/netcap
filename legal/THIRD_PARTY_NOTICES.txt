Bundled Linux runtimes
----------------------
runtime-inventory.json records every shipped loader/library hash, supplying
image identity, installed package version and exact corresponding-source link.
legal/runtime/ retains the supplying packages' copyright notices and complete
available common GPL/LGPL license texts. The lib/ directory is replaceable with
compatible modified libraries; the net launcher supplies --library-path rather
than installing libraries globally. Keep the extracted directory together.

Bundled macOS runtimes
-----------------------
native-runtime-inventory.json records the exact library hashes, installed
Homebrew supplier versions, source URLs and source hashes. The separate macOS
runtime source asset contains those complete source archives and original build
recipes. legal/native-runtime-notices.txt retains upstream notices. Native code
is unchanged; Netcap relocates Mach-O install names and ad-hoc signs the copies.
Libraries remain dynamically linked and replaceable with compatible modified
versions; reverse engineering for debugging those changes is not restricted.

The URLs above provide the exact corresponding library source, including build
scripts, at no charge. Netcap does not modify these libraries. Release pages
also provide a netcap-third-party-source archive containing these exact source
archives so corresponding source remains available with the binaries.
