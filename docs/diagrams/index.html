Source snapshot and regeneration

All seven diagrams describe Netcap at commit 4b0b2d8. The main overview retains the original capture-to-investigation layout. Arrow order in the sequence is illustrative; it is not a latency measurement.

Open index.html locally, or open any standalone diagram HTML directly. Generated diagrams embed their viewer assets, source excerpts and software notices. The editable specifications are under specs/; automation receipts and content hashes are summarized in verification.json.

With Archify installed globally, run these commands from the repository root. Set ARCHIFY_CLI to a custom bin/archify.mjs path when needed. Rendering uses Node.js 18+ and Archify's browser-check runtime.

node docs/diagrams/render.mjs
node docs/diagrams/render.mjs --check

The render command verifies sources against the pinned revision and runs validation, delivery, artifact checks and browser checks. Pass a diagram name, such as distributed, to rebuild just that view. It publishes verification.json only when every diagram has a current passing receipt. --check checks specification and HTML hashes against that record; it does not rerun browser checks. The published receipts distinguish automated verification from visual review.
